Kişisel Web Sitesi

Bu proje, geliştirdiğim "kişisel web sitesi" uygulamasıdır.  
Amaç; kendimi tanıtmak, CV’mi paylaşmak ve iletişim bilgilerimi sunmaktır.

🚀 Kullanılan Teknolojiler
- HTML, CSS, JavaScript
- Python & Django (backend)
- PostgreSQL (veritabanı)
- Bootstrap (frontend tasarım)
- Docker (geliştirme/deploy ortamı)

✨ Özellikler
- 📄 Hakkımda sayfası
- 📑 CV dosyası yükleme ve indirme
- 📬 İletişim formu
- 🌐 Mobil uyumlu tasarım
